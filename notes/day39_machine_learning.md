## Key Takeaways

- AWS offers two main categories of machine learning services: fully managed pre-trained AI services and services that allow you to build, train, and deploy custom machine learning models.

- Services such as Amazon Rekognition, Comprehend, Textract, and Polly provide pre-trained capabilities that can be implemented quickly with minimal machine learning expertise.

- Amazon SageMaker provides a comprehensive platform for building, training, and deploying custom machine learning models at scale, offering greater flexibility for organizations with specific or complex use cases.

- Understanding when to use a pre-trained AI service versus building a custom model is important for making cost-effective and efficient architectural decisions.
