## Key Takeaways

- Security and Compliance in AWS is achieved through a layered approach using multiple services that provide threat detection, vulnerability management, centralized visibility, encryption, and continuous compliance monitoring.

- Services such as GuardDuty, Inspector, and Macie focus on identifying threats, vulnerabilities, and sensitive data, while Security Hub aggregates findings into a single dashboard for improved visibility and response.

- AWS Config plays a critical role in tracking resource configuration changes and enforcing compliance rules over time.

- Encryption and key management through KMS (and CloudHSM for higher security requirements) are foundational to protecting data at rest and in transit.

- Network security services such as WAF, Shield, and Network Firewall provide layered protection against common web attacks and DDoS threats.

- A strong understanding of how these services interconnect is essential for designing secure and compliant AWS architectures.
