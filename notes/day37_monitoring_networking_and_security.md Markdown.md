## Key Takeaways

- CloudWatch provides essential visibility through metrics, logs, and alarms, enabling proactive monitoring and automated responses to performance or availability issues.

- CloudTrail delivers accountability by logging API activity across the AWS account, supporting auditing, security investigations, and compliance requirements.

- A VPC serves as the foundational private network in AWS, enabling resource isolation, secure traffic control, and scalable architecture design.

- Public subnets are used for internet-facing resources, while private subnets protect internal systems. Internet Gateways and NAT Gateways facilitate secure inbound and outbound connectivity.

- Route 53 functions as AWS’s global DNS service, intelligently routing traffic to optimize performance and reliability.

- Security and Compliance services such as GuardDuty, Security Hub, and Config provide threat detection, centralized visibility, and continuous compliance monitoring.
